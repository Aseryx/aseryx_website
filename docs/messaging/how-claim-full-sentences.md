# How claim — full sentence options

**Replace this (redundant with hero):**  
Turn your live database into a dataset. Then verify that dataset is useful. The database stays where it is.

**Shape:** two or three short sentences. Same weight as the line above. No hero echo of “Turn your live database into…”

---

## 1 · Path (recommended)
Scan your database. Lock a dataset. Check if it is useful. The database stays where it is.

## 2 · Tables first (+ access) · shipped
Scan for tables and fields that belong together. Lock them as a dataset and check if they are useful. The database stays where it is. When you are ready, you give access for a time you set.

### 2a
Pick tables and fields that belong together. Lock them as a dataset and check if they are useful. Then you can give access. The database stays where it is.

### 2b
Pick tables and fields that belong together. Lock them as a dataset and check if they are useful. Give access only when you choose. The database stays where it is.

### 2c
Pick tables and fields that belong together. Lock them as a dataset and check if they are useful. Open access for a set time. The database stays where it is.

### 2d (tight)
Pick tables and fields that belong together. Lock them as a dataset and check if they are useful. Give timed access when you want. The database stays where it is.

## 3 · Verify lead
Know if a dataset is useful before anyone trains or pays. Scan what is running, lock what you pick, then check it. The database stays where it is.

## 4 · Soft path
One path for what you already run. Scan. Lock. Check. Keep the database where it is.

## 5 · Utility
Scan what is live. Lock a dataset. Prove it is useful before it is used. The database does not move.

## 6 · Owner control
You choose what goes in. You lock a dataset. You see if it is useful. The database stays on your side.

## 7 · Shortest three
Scan. Lock. Check. The database stays where it is.

## 8 · Belong-together
Find tables and fields that belong together. Lock that as a dataset. Check if it is useful. Nothing else leaves with it.
